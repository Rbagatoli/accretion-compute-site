# accretioncompute.com

Brand site for Accretion Compute (Ion Group). A static site served by GitHub Pages, generated by a small Node script that needs no dependencies.

## Layout

- `src/layout.html`: the shared page shell (head, header, nav, footer).
- `src/pages/*.html`: one file per page. Each starts with a JSON comment: `title`, `description`, `nav`, and optional `out` and `noindex`.
- `src/partials/*.html`: reusable pieces, pulled in with `<!--include:name-->` (for example `disk` and `cta`).
- `styles.css`, `site.js`: the design system and the small script for the menu, scroll reveals and the contact form.
- `assets/logos/`: final logo SVGs from the brand kit. Never retype the wordmark in a font; use these files.
- `assets/og-image.png`: 1200x630 link-preview image.
- Favicons and `site.webmanifest` sit at the root.
- No `CNAME` yet: add one containing `accretioncompute.com` once the domain is registered.

The `.html` files at the root are build output. Edit `src/`, then rebuild. Do not edit the root files by hand.

## Build

    node tools/build.mjs

This writes every page to the root, stamps the asset version and regenerates `sitemap.xml`. Commit the built files: GitHub Pages serves them as they are.

## Preview locally

    python -m http.server 8790

then open http://localhost:8790.

## Copy rules

Accretion is pre-revenue. Never state capacity, uptime, customers or certifications that do not exist yet. Diagrams are labelled as illustrative and must not depict a real built site.

## Before launch

- Register accretioncompute.com and point it at GitHub Pages.
- Set up the `hello@accretioncompute.com` mailbox (the contact page uses it).
